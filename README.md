# WEB_DEV_LAB
# Web Development Lab (P1–P13)

A collection of practical exercises completed as part of the **Programming for Web Development – I Laboratory** course.

## Project Structure

The repository is organised into individual folders for each practical:

| Practical | Description |
|---|---|
| P1 | Terminal and project-folder navigation |
| P2 | Portfolio repository and initial Git commit |
| P3 | Feature branches and Git workflow |
| P4 | GitHub README and version tags |
| P5 | Semantic bio page |
| P6 | Portfolio structure using semantic HTML |
| P7 | CSS design tokens and typography |
| P8 | Sticky navbar and card overlays |
| P9 | Responsive layouts using Flexbox |
| P10 | Portfolio header and footer using Flexbox |
| P11 | Three-column newspaper layout using CSS Grid |
| P12 | Portfolio projects grid using CSS Grid |
| P13 | Comparison of Flexbox and Grid |

Each practical has its own folder containing the required source files.

## Screenshots and Outputs

- Terminal screenshots are included in the `README.md` files of the respective practical folders.
- Output screenshots are stored in the same folder as their corresponding practical.

## Technologies Used

- HTML
- CSS3
- Git
- GitHub

## How to View

1. Clone or download this repository.
2. Open the folder of the required practical.
3. Locate and open its `index.html` file in a web browser.
4. View the practical output directly.

No additional installation is required for the HTML and CSS practicals.
