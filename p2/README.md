P2: Portfolio Repository with an Initial Commit

Aim: To create a Git repository for a portfolio project and make the initial commit.

Procedure:

Create a project folder.
Navigate into the folder.
Initialize Git.
Create an HTML file.
Add the file to the staging area.
Commit the changes.
Commands: mkdir portfolio cd portfolio git init

Create an index.html file:(touch index.html open -e index.html //Write the cde there, format it as plaint text and rename the .txt to .html

Check the Git status: git status

Add the file: git add index.html

Commit the changes: git commit -m "Initial portfolio commit"

Check commit history: git log

Result: Successfully created a portfolio Git repository and made the initial commit.
